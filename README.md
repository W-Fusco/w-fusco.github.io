# Site de Wilson Fusco

Site estático preparado para hospedagem no GitHub Pages. O visual e a estrutura seguem a direção da conversa de referência, sem reutilizar os dados pessoais ou as publicações do amigo. O conteúdo biográfico foi extraído do Currículo Lattes de Wilson Fusco, atualizado em 17/11/2026.

## Personalizar

Edite `data/profile.json` com biografia, temas, projetos, ensino, currículo, apresentações e links. `data/auto/stats.json` contém uma seleção de publicações identificadas no currículo. A página inicial mostra três registros recentes e a página de publicações mostra a seleção completa. Indicadores de citação e ranking de trabalhos mais citados só serão exibidos quando houver uma fonte de dados configurada e conferida.

Para ver o site localmente, sirva esta pasta por HTTP, por exemplo com `python -m http.server 8000`, e abra `http://localhost:8000`. Abrir o arquivo HTML diretamente pode impedir a leitura dos arquivos JSON pelo navegador.

## Para completar a publicação

- Fotografia profissional, se desejar.
- Endereço de e-mail público, se desejar exibir um contato direto.
- Repositório GitHub onde o site será publicado.
- Identificador de perfil OpenAlex ou Semantic Scholar, caso deseje atualização automática de publicações e citações.

Nenhuma informação pessoal do site de referência foi copiada para este projeto.
